# Fulltime Press

An independent sports magazine concept with a cover feature, six sport categories, and original AI-generated editorial photography. All stories are evergreen editorial pieces.

## Run locally

From the repository root, run `python3 -m http.server 8000 --directory public` and open http://localhost:8000.

## Deploy

Import this repository into Vercel. It serves the `public` directory directly, with no dependencies or build command.
